# Code of Conduct

## Our Commitment

RetailSync should be a respectful, collaborative project for everyone participating in the repository, discussions, reviews, and demos. Harassment, hostility, discrimination, or intentionally disruptive behavior are not acceptable.

## Expected Behavior

- Be respectful in feedback, reviews, and discussion.
- Assume good intent and clarify before escalating.
- Focus criticism on code, decisions, and outcomes, not people.
- Share context clearly so others can contribute safely and effectively.
- Respect privacy, credentials, and sensitive project information.

## Unacceptable Behavior

- Harassment, personal attacks, or intimidation
- Discriminatory or demeaning language
- Deliberate sabotage, trolling, or repeated bad-faith behavior
- Sharing private credentials, sensitive data, or personal information without permission

## Scope

This code of conduct applies to:

- the GitHub repository and pull requests
- issues, discussions, and code reviews
- project demos, presentations, and class collaboration related to this repository

## Reporting

If you experience or witness behavior that violates this code of conduct, contact the project maintainer privately at `trupal.work@gmail.com`.

Include:

- what happened
- where it happened
- who was involved
- any screenshots or supporting context if available

## Enforcement

The maintainer may remove comments, limit participation, or block contributors whose behavior harms the project or other participants.
