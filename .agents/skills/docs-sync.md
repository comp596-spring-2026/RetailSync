# Skill: Docs Sync

## Use This When

A task changes:

- routes
- visible workspace structure
- supported modules
- test confidence
- release posture

## Workflow

1. identify which visible product truths changed
2. update README
3. update status/audit docs
4. update relevant wireframes
5. update release notes or PR markdown if needed

## Must-Check Edge Cases

- inventory accidentally described as active
- procurement overstated
- QuickBooks described as accounting tab
- test confidence overstated
